SECTION 1 — PROBLEM STATEMENT
EduMind AI is built to solve deeply interconnected pain points facing students, parents, and teachers in India —
especially in Tier 2/3 cities and engineering colleges.
1.1 Student Pain Points
What Students Are Struggling With
■ Rote Learning Trap: 76.6% of Class 3 students cannot read grade-level text (ASER 2024).
■ Exam Pressure: No personalised support; one-size-fits-all teaching creates anxiety.
■ No On-Demand Help: Teachers unavailable after school hours; doubt resolution delayed by days.
■■ No Study Roadmap: Students don't know what to study, in what order, or how much time to spend.
■ Information Overload: YouTube, PDFs, notes — but no coherent system to tie them together.
■ Skill-to-Job Gap: Curriculum disconnected from actual internship and job requirements.
■ Language Barrier: Core concepts taught in English; many students think in Telugu/Hindi.
■ No Feedback Loop: Assignments returned with just a score — no explanation of mistakes.
1.2 Teacher Pain Points
What Teachers Are Struggling With
■ Admin Overload: Teachers spend 30-40% of time on paperwork, attendance, and non-teaching tasks.
■ Lesson Planning from Scratch: Each chapter requires hours of planning with no AI assistance.
■ No Differentiated Teaching: One lesson plan must serve 40+ students at different levels.
■ No Class Performance Analytics: Teachers can't identify struggling students without manual checking.
■ Communication Chaos: 3-4 WhatsApp groups per class; buried messages; no read receipts.
■ Assessment Generation: Manually creating quiz variants to prevent copying is time-consuming.
1.3 Parent Pain Points
What Parents Are Struggling With
■ Zero Visibility: Parents don't know daily attendance, homework, or exam schedules in real-time.
■ WhatsApp Chaos: Fee reminders, event notices, and memes all in the same group.
■ No Academic Progress Tracking: Report cards once/twice a year; no ongoing mastery visibility.
■ Language Barrier: School circulars in English; many parents more comfortable in regional languages.
■ Event Miss: Annual days, PTMs, fee deadlines — missed due to poor communication.
■ Fee Transparency: No easy way to check what's paid, pending, or due — leads to disputes.

SECTION 3 — MODULE 1 — AI STUDY COMPANION
(NotebookLM-Inspired)
Feature 1: Source-Grounded Q&A; (RAG Chat)
Student uploads course PDFs, lecture notes, YouTube links, and images.
AI answers ONLY from those uploaded sources — no hallucination.
Every answer shows citation: "Source: Chapter 3, Page 47, Thermodynamics.pdf"
Multimodal: supports text, images of diagrams, and scanned handwritten notes (via OCR).
Multi-source synthesis: "Compare what Chapter 2 and Chapter 5 say about this concept."
Feature 2: Interactive Mind Maps
Auto-generate visual mind maps from any uploaded document or topic.
Hierarchical branching: Topic → Subtopics → Key Facts → Related Concepts.
Click any node to expand details or open a focused Q&A; chat on that concept.
Export as PNG/PDF. Student can manually add nodes and connections.
Mind map updates as new sources are added to the notebook.
Feature 3: Audio Overviews (Podcast Mode)
Convert any document into a 5-15 minute conversational audio summary.
Three formats: Brief (single host), Debate (two AI hosts), Deep Dive (technical walkthrough).
Audio playback speed control: 0.75x to 2x. Auto-transcript with timestamps.
Feature 4: Auto-Generated Study Aids
Flashcards: Term-Definition cards with spaced repetition scheduling.
Quizzes: MCQ, fill-in-the-blank, short answer — tagged by topic and difficulty.
Summary Notes: Chapter-wise summaries in bullet or paragraph form.
Key Formulas Sheet: Extracts all equations from science/math notes.
Comparison Tables: "Compare X vs Y" → structured table output.
Feature 5: Multilingual Socratic Tutor
AI asks guiding questions instead of giving direct answers — builds reasoning.
Adjusts depth: "Explain like I'm 12" to "Explain at JEE Advanced level".
Explains in Telugu, Hindi, or Hinglish with English technical terms.
Session memory: remembers what was covered in previous sessions within a notebook.

SECTION 8 — SYSTEM ARCHITECTURE
Layer 1 — Data (Supabase)
Document Store: Supabase Storage — uploaded PDFs, slides, images (per user, per notebook).
Vector Store: pgvector (Supabase PostgreSQL) — embeddings for RAG retrieval.
Auth: Supabase Auth — role-based (Student/Teacher/Parent/Admin); SSO for schools.
Realtime: Supabase Realtime — parent attendance alerts, live quiz scores.
Row-Level Security: Each user sees only their school's data.
Layer 2 — AI (Flexible — Paid or Free)
Primary LLM: Claude claude-sonnet-4-6 (Anthropic) OR Gemini 2.5 Flash (free) OR Groq Llama 3 (free).
RAG Pipeline: LangChain — chunk → embed → retrieve → generate with citations.
Embedding Model: Gemini text-embedding-004 (free) or OpenAI text-embedding-3-small.
Mind Map Generator: LLM outputs JSON tree → D3.js/React Flow renders interactive map.
Audio Overview: ElevenLabs TTS (paid) OR Web Speech API (free).
Vision/OCR: Gemini Vision — processes blackboard photos, textbook scans, diagrams.
Translation: Gemini Flash handles multilingual natively — no separate API needed.
Layer 3 — Application (Vercel)
Frontend: React (Vite) + Tailwind CSS + shadcn/ui — mobile-first PWA.
Backend: Supabase Edge Functions (Deno) for AI orchestration.
Deployment: Vercel (frontend) — auto-deploy from GitHub.
Push Notifications: OneSignal (free) for parent alerts and study reminders.
Payments: Razorpay (optional) for school fee collection.
Step
RAG Pipeline Action
1 — Upload
Student uploads PDF → Supabase Storage → file URL saved to sources table.
2 — Extract
Edge Function: pdf-parse for text; Gemini Vision for images.
3 — Chunk
Split into 512-token overlapping chunks with LangChain TextSplitter.
4 — Embed
Each chunk → embedding API → vector stored in pgvector.
5 — Query
Student question → embed → top-5 similar chunks retrieved via cosine similarity.
6 —
Generate
Chunks + question → LLM → answer with page citations.
7 — Display
Answer in chat with source citation links.

SECTION 10 — DATABASE SCHEMA (Supabase PostgreSQL)
-- Enable pgvector
CREATE EXTENSION IF NOT EXISTS vector;
-- Schools
CREATE TABLE schools (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  name text, type text, city text, board text, created_at timestamptz DEFAULT now());
-- Users
CREATE TABLE users (id uuid PRIMARY KEY REFERENCES auth.users(id),
  email text, role text, school_id uuid REFERENCES schools(id),
  full_name text, avatar_url text, language_pref text DEFAULT 'en');
-- Notebooks & Sources
CREATE TABLE notebooks (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid REFERENCES users(id), title text, subject text,
  created_at timestamptz DEFAULT now());
CREATE TABLE sources (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  notebook_id uuid REFERENCES notebooks(id),
  type text, file_url text, raw_text text, uploaded_at timestamptz DEFAULT now());
-- Embeddings (pgvector)
CREATE TABLE embeddings (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  source_id uuid REFERENCES sources(id),
  chunk_text text, chunk_index int, embedding vector(768));
CREATE INDEX ON embeddings USING ivfflat (embedding vector_cosine_ops);
-- Quizzes & Results
CREATE TABLE quizzes (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  teacher_id uuid REFERENCES users(id), class_id uuid,
  title text, question_ids uuid[], time_limit_mins int, due_date timestamptz);
CREATE TABLE quiz_submissions (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  quiz_id uuid REFERENCES quizzes(id), student_id uuid REFERENCES users(id),
  answers jsonb, score numeric, ai_feedback jsonb, submitted_at timestamptz DEFAULT now
());
-- Events & Announcements
CREATE TABLE announcements (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid REFERENCES schools(id), target text,
  title text, body text, read_by uuid[] DEFAULT '{}', sent_at timestamptz DEFAULT now()
);
CREATE TABLE events (id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  school_id uuid REFERENCES schools(id), title text,
  event_date timestamptz, venue text, rsvps jsonb DEFAULT '{}');
